## 迭代时间线

### 第 0 轮 · 调研与选型

- **输入**：全网调研 dlssg_for_sm86 / DLSS Unlocked / OptiScaler / DLSS5-Swapper 四个项目
  （star、机制、上游文档），结论：dlssg_for_sm86 是插帧核心，DLSS5-Swapper 补 DLSS 5 画质，
  两者可分层组合；瓶颈是基础帧率（≥55–60 再开 4X）。
- **决策**：不做渲染算法，做**安装编排器**（冲突规则、校验、还原、诊断）。

### 第 1 轮 · 构建（superpowers 全流程）

- 流程：brainstorming → [设计 spec](../superpowers/specs/2026-09-20-dlss-combo-design.md) →
  [实施计划](../superpowers/plans/2026-09-20-dlss-combo.md)（12 任务）→ TDD 红绿循环 → 验证。
- **产出**：`dlss-combo` Python CLI（fetch/install/uninstall/doctor），81 测试，
  真实网络探针验证下载链路（上游 commit 固定 + SHA256）。
- **已知诚实缺口（当时声明）**：`--launch-swapper`、驱动 ≥R580 检查未实现。

### 第 2 轮 · 自查审查 + 实测

- 环境无法派审查子代理（reasoning-level-missing）→ 按同模板**内联严格自查**。
- **发现并修复**：重装删除范围未限定（manifest 可被外部编辑）、回滚不还原已删代理；
  补齐两个已声明缺口（驱动检查、`--launch-swapper`）。
- **实测**：真实全量 fetch（413MB），文件字节数与 GitHub API 元数据逐字节一致；
  真实 kit 安装/篡改检测/卸载演练通过。

### 第 3 轮 · 外部项目审查（A–J，九项可复现缺陷）

- 详档：[2026-09-20-project-review.md](../reviews/2026-09-20-project-review.md)；
  复现脚本：[2026-09-20-repro.py](../reviews/2026-09-20-repro.py)。
- **修复**：manifest 路径/schema 验证（A）、哈希所有权（B）、预存 INI 备份还原（C）、
  校验强度与缓存/启动前校验（D/J）、原子写与回滚（E）、kit 事务性与分运行库 commit（F）、
  doctor 准确性（G）、代理顺序按上游工具类优先 + `--proxy`（H）、能力组合检查（I）。
- 测试夹具改为**真实哈希**（审查指出原夹具把漏洞固定成了通过）。
- 107 测试 + 复现脚本 9/9 observed=false；Windows CI 当场抓到两个 cp1252 编码缺陷（已修）。

### 第 5 轮 · 发布验收审查 → v0.1.1

### 第 6 轮 · v0.1.1 独立复核 → v0.1.2

- 详档：[2026-09-20-v0.1.1-independent-review.md](../reviews/2026-09-20-v0.1.1-independent-review.md)；
